## Comparison with our delivered source

Source under comparison: 68895fd62b7806e5c5bbea9dfd559f1c2af2c14b in Yunbo-max/theory.
Inspected methods.target, train.record_loss and runner.worker/generate_records.

Our full_soft loss is H(mu_r,p_theta), equivalent to KL(mu_r||p_theta) up to the detached target entropy. Here mu_r is the previous round's own model after temperature/top-k/top-p. Prefixes are generated once per round, then reused throughout that training phase. Thus the loss belongs to the forward-KL distillation family, but this code is not an exact GKD reproduction: target construction, teacher refresh and sampling cadence differ. Forward-KL membership itself is not novel.

## Proposed discriminating comparisons (not yet implemented/queued)

1. Retain hard SSD, full_soft and arithmetic_anchor from the current frozen run.
2. Compare matched own-policy forward-KL, reverse-KL and JSD objectives with the same model, transformed teacher targets, prompt budget, refresh schedule and evaluator. Label them GKD-inspired self-policy adaptations.
3. Separately vary per-update student rollouts versus round-wise cached rollouts to isolate data-distribution mismatch; do not combine that change with a new loss and attribute the whole effect to the loss.
4. If a stronger or additionally supervised teacher is introduced, report it as an additional-information reference. It is not an equal-information primary comparison for our strict setting.

Mathematical check: with an exactly identical untransformed frozen teacher/student at initialization, equal context/temperature, deterministic mode and no auxiliary term, forward-KL logit gradient p_student−p_teacher is zero. Merely renaming a copy as a teacher does not create an improvement signal. Our decoder transform is one explicit source of target asymmetry.

Support check: top-k/top-p yields exact target zeros; reverse KL from a full-support student can then be infinite. A declared full-support target, for example mu_eps=(1−eps)mu+eps p_r, is needed for that comparison. Apply the same target to all compared divergences and charge the change explicitly. JSD remains finite with disjoint support.

Fairness/prediction: if changing divergence or rollout freshness explains the candidate's apparent gain, the claimed need for the floor constraint weakens. If the candidate beats these controls on native correctness while retaining useful multi-sample coverage across rounds, that supports a narrower recursive-constraint hypothesis. More entropy by itself is insufficient.
